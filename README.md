# PlanetHunting
Hunt for a planet that fits your living preferences (planet size, temperature, brightness, and year length)!
Takes data from exoplanetarchive.caltech! (shoutout to the true beavers jk)
Coded in Java and uses the Apache Maven Java tool. In the .zip file you will find the whole Java project, including the pom.xml.
Installation:
1. unzip the .zip
2. Run the planetHunting.java file: ./planet-hunting/src/main/java/com/planethunting/planetHunting.java
